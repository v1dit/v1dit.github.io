# v1dit.github.io

Personal portfolio for Vidit Agarwal. A dependency-free static site with a
mouse-responsive Braille icosahedron, professional experience, hackathon
placements, and selected projects.

## Run locally

```sh
python3 -m http.server 8000
```

Open `http://localhost:8000`.

## Content

Experience, awards, and project data live at the top of `app.js`. The résumé
link points to `resume.pdf` in the site root.
